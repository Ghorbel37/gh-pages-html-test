# GitHub Pages: plain HTML

A one-page static site used to try out GitHub Pages with plain HTML.

**Live site:** https://ghorbel37.github.io/gh-pages-html-test/

## How it's deployed

GitHub Pages serves `index.html` directly from the root of the `main` branch. Any change pushed to `main` is published automatically.
